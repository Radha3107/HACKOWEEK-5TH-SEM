# DataPulse — Student Performance Analysis

## Overview

DataPulse is a simple Python-based data analysis project developed for Hack-o-week W03–W04. It demonstrates Python programming, NumPy, Pandas, and data visualization using Matplotlib and Seaborn.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Topics Covered

- Python functions
- Object-Oriented Programming
- List and dictionary comprehensions
- NumPy arrays
- Broadcasting and vectorized operations
- Pandas DataFrames
- Data cleaning
- Data merging
- GroupBy operations
- Matplotlib visualization
- Seaborn visualization
