# W05-W06 — Mathematics for Machine Learning

## Overview

This project explores the mathematical foundations required for understanding Machine Learning and neural-network training. The implementation uses Python and NumPy to demonstrate key concepts from Linear Algebra and Calculus.

## Topics Covered

### Linear Algebra
- Vectors and vector operations
- Vector magnitude
- Dot product
- Matrix operations
- Matrix-vector multiplication
- Eigenvalues and eigenvectors

### Calculus
- Derivatives
- Numerical differentiation
- Gradients
- Chain rule
- Gradient descent
- Backpropagation intuition

## Implementation

`math_notes.py` provides practical NumPy-based demonstrations of the concepts.

`concepts.md` contains the mathematical explanations, formulas, and their connection to Machine Learning.
